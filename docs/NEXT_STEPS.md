# 下一步实施计划

## 1. 组件与配置（已完成首版）

交付：ComponentResolver、版本读取、ConfigGenerator、配置检查。

- 记录明确的组件版本与真实路径。区分候选检测与用户选择。
- 原生校验扩展到 dylib、PHP 扩展及运行进程，Intel-only 组件不能启动。
- 确认依赖后提供安装预览；不执行隐式 brew upgrade，不修改其他服务。
- 生成 MacStack 专属 Apache/PHP-FPM 配置。数据、日志、PID、socket 分离。
- socket 使用短路径，避免 Unix socket 长度上限。
- Apache 使用 PHP-FPM；识别 .htaccess 中 mod_php 的 php_value/php_flag 差异。
- 测试包含空格及中文的网站路径，配置保存前先语法检查。

验收结果：已从独立目录经 Apache/PHP-FPM 执行 PHP 8.2.33，返回 `MacStack PHP OK`，只监听 127.0.0.1:8080，全程无管理员密码。空格和中文路径已覆盖生成器测试；真实业务项目兼容性仍需逐个验证。

## 2. 真正的服务控制与多站点（0.9 已完成日常管理闭环）

交付：实现 ServiceControlling 的进程管理器、端口检测、健康检查和服务日志。

- 使用 Foundation.Process 的 executableURL + arguments，不把用户输入拼入 shell。
- 明确停止、启动中、运行中、停止中、失败状态；防止重复启动。
- PID 不是唯一身份依据，停止前同时校验可执行路径及自身配置。
- 读取输出避免管道阻塞，限制日志长度；退出码和超时要可见。
- 进程存在不等于就绪：用 HTTP/PHP 响应与数据库查询验收。
- 窗口关闭、Command-Q、应用异常退出和重开都要设计处理；先做随应用正常停服，再考虑后台模式。

当前结果：已实现直接进程句柄管理、重复启动保护、PHP HTTP 健康检查、正常停止、启动失败回滚、启动器日志，以及应用退出前收尾。网站可选择项目根/`public` 目录并获得稳定独立端口；启用、停用或编辑时会先验证候选配置，再受控重启，失败则恢复上一份配置。已用两个真实站点验证 PHP、静态 HTML/CSS、停用隔离、隐藏路径 403、稳定端口和端口冲突回滚；没有启动或停止旧 XAMPP。

当前应用会定期检查自己启动的 Apache、PHP-FPM 和 MariaDB；意外退出会更新界面状态，Web 半运行状态会被收尾。

0.9 新增 Start All / Stop All、上次服务状态恢复、可选随应用启动、强退残留的 PID + 专属配置路径双重核对，以及 5 MB/3 份日志轮转。仍需更多连续启停和真实界面点击回归。

## 3. MariaDB 与 phpMyAdmin（首版核心已完成）

交付：独立数据目录初始化、钥匙串凭据、数据库健康检查、phpMyAdmin 入口。

- 初始化前确认目录为空；禁止以“修复”为由重新初始化已有数据。
- 固定 datadir、socket、端口 3307 和仅本机访问；避免读取旧 /etc/my.cnf。
- 正常关闭并等待完成，超时报告，不默认强杀数据库。
- phpMyAdmin 使用匹配 PHP 版本的发行包并验证校验和。
- 首先以测试库验证建表、增删改查、SQL 导出及恢复。

当前结果：MariaDB 11.4.13 使用独立数据、配置、PID、socket 和日志目录，只绑定 127.0.0.1:3307；真实查询、正常关闭、重复准备和端口冲突已验证。开发账号凭据使用 macOS 钥匙串。phpMyAdmin 5.2.3 使用隔离副本与 cookie 登录，登录页已通过全栈 HTTP 验收。

当前结果：原生界面已支持业务数据库列表、单库 SQL 导出和确认后恢复。真实闭环测试已验证中文数据、视图和触发器能够在删库后从备份恢复；导出参数同时包含事件和存储过程。

0.9 新增数据库创建、PDO 模板、大 SQL 空间预检/进度/取消、备份历史和 1–168 小时自动备份。仍需用数 GB 级真实备份做压力测试，并完成 phpMyAdmin 登录点击回归。

## 4. 旧 XAMPP 迁移（网站与数据库逻辑路径已接入）

- 已实现只读网站、扩展、配置、数据库目录和旧二进制架构清单；报告不记录密码或配置片段，不运行旧组件。
- 已实现保留原网站的迁移副本：先预览和二次确认，拒绝既有目标与符号链接，复制前后校验 SHA-256，失败不发布半成品。
- 数据库用逻辑导出/导入，不复用旧物理数据目录。
- 单独处理账号权限、触发器、视图及存储过程；测试备份可恢复。
- 逐个验证真实项目登录、上传、Session、表单和数据库写入。
- 通过后才讨论旧环境清理。

当前本机结果：`mystudy` 是唯一网站候选，仅包含 28 字节的 `index.php`；可见数据库目录均为系统库，没有发现明显业务库。0.9 可以用临时 0600 连接文件只读连接正在运行的旧数据库，逐库确认后逻辑导出并导入，密码不保存、源库不修改。由于本机没有旧业务库，直接旧库迁移仍缺真实数据闭环；网站复制已由隔离 fixture 验证。
